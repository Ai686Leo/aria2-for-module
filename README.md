**Project Update Discontinuation Notice**

Regret to inform you that, due to increasingly strict certificate policies in the Android and Chrome kernels, the methods this project relies on have become invalid, and the project can no longer run. I have therefore decided to stop updating it as of September 19, 2026.

All files and releases will be retained and will not be deleted, in case other viable solutions are found in the future.
